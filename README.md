# AI 花店 3D Studio

一个本地优先的 AI 花店网页 MVP：上传鲜花照片、选择花材、调整花束参数，并实时生成 3D 花束预览。

## 当前功能

- 3D 花束实时渲染，基于本地 Three.js 模块。
- 花材选择按花店逻辑分类：主花、副花 / 线条花、配花、叶材、包装纸。
- 每种花按“一枝花”建模：花头、弯曲枝干、节点叶片、侧枝和花苞作为一个整体生成。
- 花束按插花构图组织：主花、线条花、团块花、填充花、叶材分别承担高度、重心、疏密和轮廓。
- 当前 AI 为本地模拟规划，没有真实调用外部 API；页面会明确提示这一点。
- 参数控制：花束密度、高度层次、展开角度、绿叶比例。
- 用途场景：庆祝、求婚、家居、礼物。
- 图片上传预览，用于模拟 AI 提取花型和色彩。
- 导出当前 3D 渲染图为 PNG。

## 本地运行

```bash
npm run dev
```

然后打开：

```text
http://localhost:5173
```

也可以直接运行：

```bash
python3 -m http.server 5173
```

## 后续路线

1. 接入真实 AI 花束规划接口，返回花材、颜色、预算、构图参数。
2. 接入图像理解能力，从上传照片识别花种、色彩、形态和新鲜度。
3. 引入 React/Vite，把当前原型拆成组件。
4. 增加花材资产库，逐步替换程序化花朵为高质量 3D 模型。
5. 接入 image-to-3D 或 3D Gaussian splatting，用照片生成可旋转花材模型。
